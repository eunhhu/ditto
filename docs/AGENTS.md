# Documentation rules

- State what is implemented separately from what is designed or deferred.
- Never mark a roadmap item complete from compilation alone.
- Public contract changes update the matching spec and usually an ADR.
- Keep `docs/agent/HANDOFF.md` factual and current after substantive work.
- Keep root `AGENTS.md` compact; route detail into `docs/agent` instead of
  copying the same rule into several files.
- Examples must match current type names, endpoints, and manifest syntax.
